# 평가 규칙과 해석 범위

## 주 지표

각 이미지에서 클래스별 IoU를 계산하고 클래스 평균을 낸 후, 이미지들을 같은 비중으로 평균합니다. 전체 영상의 픽셀을 합산한 pooled IoU가 아닙니다.

- `skip`: GT와 예측 모두 없는 클래스는 그 이미지 평균에서 제외.
- `1`: 같은 경우 IoU=1로 포함.
- `0`: 같은 경우 IoU=0으로 포함.

GT에 없지만 예측한 클래스는 union>0이므로 세 관례 모두 해당 클래스 IoU=0입니다. 단, 이미지 평균에 미치는 영향은 관례별로 다릅니다. 공식 평가기의 모든 세부 구현과 동일하다고 단정하지 않습니다.

```bat
python evaluate.py --labels "D:\data\valid.zip" --predictions "D:\result\hide_seg\masks" --output "D:\result\valid_metrics.json"
```

## OOF70과 validation20

| 구분 | OOF70 | validation20 |
|---|---|---|
| 대상 | 제공 train70 | 제공 valid20 |
| 기저 예측 | 각 이미지의 held-out fold 한 개 | 보정된 5개 fold 확률 평균 |
| 용도 | 반복 개발 및 후보 선택 | 최종 제출 절차 확인 |
| 주 지표 | 79.9828% | 78.5597% |

두 점수 차이를 그대로 선택 편향의 크기로 해석하지 않습니다. 데이터, 모델 개수, 평균 단계가 다릅니다. validation20도 초기 개발에서 사용한 이력이 있어 완전히 미사용인 독립 holdout은 아닙니다.

## 분할과 후처리의 의존성

A번호 접두어를 기준으로 그룹을 유지한 5-fold를 사용합니다. 파일명에 합금·공정·시편의 물리 의미를 부여하지 않습니다. 분할 목록에는 이미지 ID만 포함하며 픽셀 데이터와 GT는 공개하지 않습니다.

IS-P는 해당 fold의 in-sample 기저 확률로 학습합니다. 따라서 기저 모델이 학습 때 본 이미지의 오류 분포와 held-out 오류 분포 차이가 남습니다.

Si 재판별기는 다른 fold에서 생성한 보정 OOF 특징을 모아 적합합니다. 평가 fold의 이미지를 재판별기 적합 표본에 직접 넣지는 않지만, 다른 기저 fold 모델을 통한 간접 의존성이 남습니다. 전체 과정을 매 outer fold 안에서 다시 학습한 엄밀한 nested CV가 아닙니다.

## 결과에서 하지 않은 해석

- 파일명 그룹을 처음 보는 합금에 대한 일반화로 해석하지 않습니다.
- GT 경계 띠의 오류가 모두 경계 위치 오차인 것은 아닙니다. 얇은 ESi 전체가 띠에 포함될 수 있습니다.
- 서로 다른 기준의 실험 상승폭이나 가상 교정 상한을 합산하지 않습니다.
- test10은 GT가 없으므로 이 저장소에서 성능 점수를 제시하지 않습니다.
