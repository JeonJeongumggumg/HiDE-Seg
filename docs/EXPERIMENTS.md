# 실험에서 선택한 것과 남긴 질문

목표는 얇은 조직을 더 검출하면서 올바른 상 판정을 유지하는 것이었습니다. ESi recall 하나만 높이는 조건보다 **이미지별 mIoU, precision, 반대 방향 오탐, fold별 방향**을 함께 확인했습니다. 아래 수치는 서로 다른 개발 비교의 기록이므로 행 사이에서 직접 순위를 매기거나 증가분을 합산하지 않습니다.

## 최종 파이프라인에 남긴 요소

| 요소 | 검증 내용 | 최종 사용 |
|---|---|---|
| HRNet + detail exchange | 입력 해상도의 세부 특징과 HRNet 문맥 특징 결합 | detail16, stage 2·3 교환 |
| DINO direct64 | 동결 자기지도 특징을 최종 분류부에 직접 연결 | stage 3 주입 + head 직접 결합 |
| 2배 입력 | 동일 원본 크롭의 처리 해상도 비교 | 384→768, 출력은 원본 좌표로 복원 |
| D4 TTA | 같은 체크포인트의 방향별 확률 평균 | 타일 단위 8방향 |
| IS-P | 확률 공간 보정, 다른 초기화와 고정 Gaussian 대조군, 5-fold 확장 | RGB 없이 seed 731의 고정 조건 |
| B2 + PCA16 | IS-P 이후 성분을 다시 생성하고 고정 조건 재학습 | 확률 요약 + 성분 평균 DINO 특징 |

최종 70장 누적 비교는 **79.1521 → 79.5327 → 79.8053 → 79.9828%**입니다. 단계별 fold 집계는 [단일 추론](../resources/single_fold_results.json), [D4](../resources/d4_fold_results.json), [공간·성분 보정](../resources/refinement_fold_results.json)에 있습니다.

## 채택하지 않은 대표 비교

| 질문 / 조건 | 평가 범위 | 관찰 | 판단 |
|---|---|---|---|
| 이미지 간 픽셀 대조 손실: joint32, λ=0.1, τ=0.1 | 5-fold, 70장, best within 60 epochs | 기준 79.1521%, 후보 78.6172%; 5/5 fold 하락, 이미지 19승/51패. 얇은 ESi recall +2.6614%p, precision −2.0076%p | 검출 증가가 전체 상 구분 개선으로 이어지지 않아 제외 |
| FreqFusion 한 지점 교체 | 2-fold, 28장, 같은 길이 계속 학습 | 대조군 80.4267%, 후보 80.4380%; 17/28장 개선 | 사전 확장 조건 미충족 |
| 원본 1픽셀 이웃 affinity | 2-fold, 28장, 같은 길이 계속 학습 | 대조군 80.4280%, 후보 80.4366%; 18/28장 개선. 원래 모델 80.5423% | 사전 확장 조건 미충족 |
| 기준 + 대조학습 모델 평균 | D4끼리 비교 | D4 이후 앙상블 채택 조건 미충족 | 가중치 추가 탐색 없이 종료 |
| 시드 앙상블 | D4 선별 → 5-fold → 후처리 재학습 비교 | D4 단계의 이득이 최종 후처리 파이프라인 교체 근거로 유지되지 않음 | 기존 제출 후보 유지 |

계속 학습 두 비교는 **대조군 대비 효과**와 **기존 best 체크포인트 대비 효과**를 구별해야 합니다. best 선택, 추가 학습, BN 통계가 함께 바뀌므로 기존 모델 대비 하락 원인을 하나로 확정하지 않았습니다. 두 fold에서 얻은 세부 지표를 전체 70장에 일반화하지 않습니다.

## 오류 분석에서 얻은 설계 질문

- 경계 가까이에 오류가 많아도 모든 오류가 윤곽 위치 문제인 것은 아닙니다. 얇은 ESi 자체가 경계 띠에 대부분 포함될 수 있습니다.
- 얇은 ESi를 더 찾는 조건에서는 Al₃Ni→ESi 오탐과 ESi precision을 함께 봐야 합니다.
- 이미 검출한 Si의 PSi/ESi 재판정과 완전히 놓친 Si 검출은 다른 과제입니다. 성분 재판별기의 효과 범위도 이에 맞춰 설명합니다.
- 같은 입력에 후처리를 더해 얻은 짝지은 개선과, 새로 학습한 모델끼리의 개선은 학습 무작위성의 영향을 다르게 받습니다. 후처리도 자체 학습 무작위성과 OOF 설정 선택의 영향을 받습니다.
- 모듈별 이득을 단순히 더하지 않고, 실제 결합 순서에서 입력을 다시 만들고 후처리를 다시 학습해 판단했습니다.

## 해석 범위

성공·실패는 이 데이터와 구현·학습량의 관찰입니다. 실패한 비교가 해당 방법론 전체의 무효를 뜻하지 않습니다. OOF70은 여러 설정을 고른 개발 데이터이고 valid20도 초기 개발에 사용한 이력이 있습니다. 파일명으로 합금·공정의 물리적 의미를 추론하지 않습니다. [정확한 평가 단위와 제한](EVALUATION.md)
