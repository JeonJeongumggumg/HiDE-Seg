다른 GPU·드라이버·라이브러리에서 같은 비트 단위 결과가 나온다는 보장은 아닙니다. 공개 저장소에는 이 검증에 사용한 가중치와 입력 영상을 포함하지 않습니다.

## 공개 코드 점검

2026-11-13 공개 준비 시 다음을 확인했습니다.

| 검사 | 결과 |
|---|---|
| 합성 입력 기반 수치·계약 검사 | 9개 통과 |
| CLI 도움말 | 9개 진입점 정상 |
| 학습 데이터 로더·크롭·지표 | 기존 5개 함수/클래스와 AST 동일 |
| 원 데이터 분할 dry-run | 5개 fold 모두 56/14, 해시·그룹 분리 통과 |
| CPU 합성 입력 모델 점검 | 순전파·역전파·optimizer 1회 갱신 정상, DINO 동결 유지 |
| 학습 가능 파라미터 수 | 9,643,750 일치 |
| 가중치가 없는 추론 실행 | 코드·문서 공개판임을 안내하고 중단 |

실제 데이터 dry-run은 분할을 읽기만 했고 공개 폴더에 영상을 복사하지 않았습니다. 합성 입력 1회 갱신은 학습 코드의 작동 점검이며 성능 실험이 아닙니다.

`src/manifest.json`에 있는 모델 외 10개 파일은 검증된 제출 소스를 바이트 단위로 보존합니다. Git 줄바꿈 변환으로 해시가 바뀌지 않도록 해당 파일의 `.gitattributes`를 지정했습니다. `src/README.md`는 과거 패키지 안내 원본이며, 공개 범위와 현재 진입점은 루트 README를 따릅니다.

다음 검사는 데이터나 가중치를 다운로드하지 않습니다.

```bat
python scripts\check_publication.py
python -m unittest discover -s tests -v
```

- 공개 범위: 텍스트·SVG만 허용, 이미지·모델 바이너리·개인 경로·credential 형태 검사
- 정적 검사: Python 문법, JSON, 내부 문서 링크, 추론 소스 SHA256
- 합성 입력 검사: 부재 클래스 mIoU, D4 역변환과 2배 복원, 직사각 영상 겹침 평균
- 보정 검사: IS-P 초기 동일 출력, RGB 비사용, Si 확률 합과 비Si 확률 보존
- 데이터·캐시 검사: GT palette, nearest 라벨 확대, 확률 캐시 해시·fold 계약, A번호 fold 분리

소스·공개 범위 검사는 Python 표준 라이브러리만 사용합니다. 수치 검사는 고정한 프로젝트 환경에서 위 명령으로 실행합니다. 이 공개본에는 GitHub Actions 워크플로를 포함하지 않습니다.

공개용 학습 진입점은 기존 최종 레시피를 추출·정리한 코드입니다. 전체 5-fold 재학습 수치 재현과 제출 추론 재현은 서로 다른 검증이며, 이번 공개 정리에서는 전체 재학습을 수행하지 않았습니다.
